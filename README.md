# Diplom_1

Юнит-тесты класса `Burger`. Дипломный проект Яндекс Практикума.

## Окружение

- JDK 11 и Maven 3.9.x.
- JUnit 4.13.2, Mockito 4.11.0, JaCoCo 0.8.14.
- Рабочая ветка: `develop1`.

Откройте `pom.xml` как Maven-проект в IntelliJ IDEA и выберите JDK 11.

## Запуск

```sh
mvn clean verify
```

Команда запускает тесты, создаёт отчёт JaCoCo и проверяет 100% покрытия
инструкций и ветвей класса `praktikum.Burger`. При снижении покрытия сборка падает.
Для запуска только тестов: `mvn clean test`.

HTML-отчёт: `target/site/jacoco/index.html`.
Страница класса: `target/site/jacoco/praktikum/Burger.html`.
В отчёте показаны все исходные классы, но обязательный порог относится только
к `Burger`, как указано в задании. Остальные классы заготовки не входят в объём тестирования.

## Проверки

- `BurgerTest`: выбор и замена булочки, добавление и удаление ингредиентов,
  перемещение вперёд, назад и на тот же индекс.
- `BurgerPriceTest`: параметризованные проверки стоимости двух половинок булочки
  и ингредиентов, включая дробные и нулевые цены.
- `BurgerReceiptTest`: параметризованные проверки полного текста чека без
  ингредиентов, с соусом, начинкой и их сочетанием; проверяются порядок и итоговая цена.

Зависимости `Bun` и `Ingredient` заменены моками Mockito; для цены и чека
заданы стабы необходимых методов. Исходный код приложения не изменён.

Сохранённый отчёт для пул-реквеста: [reports/jacoco.zip](reports/jacoco.zip).
Результаты последнего прогона: [reports/README.md](reports/README.md).
После изменения тестов необходимо обновить сохранённый архив отчёта.

После первого ревью полный отчёт дополнительно приложен распакованной папкой `jacoco/` в корне проекта. Откройте её `index.html`; архив также сохранён.
